SheetSpeed Core (“Core”) is a Chrome extension that adds keyboard shortcuts and a command panel to Google Sheets and Google Slides documents you already have open. Core does not use Google API OAuth, does not contact an AI helper, and does not send extension data to SheetSpeed developer servers.

Data Core accesses

  • Document context on matching pages. On Google Sheets and Slides document URLs, Core reads visible formula text, document/tab identifiers, the selected range, and native menu/control metadata needed to run a command you invoke.
  • Keyboard events. Core inspects key events to match configured shortcuts and to operate its own panel. Local diagnostics may retain the latest modifier event and element/menu metadata for troubleshooting; this is not an analytics upload.
  • Current page URL. The popup and document handlers read the current document URL only to confirm eligibility and identity. Core does not query Chrome browsing history.

Storage

  • Core stores local shortcut overrides, enabled state, and sequence timeout in Chrome extension local storage.
  • If you previously used SheetSpeed Full under the same extension identity, Core preserves existing Full recovery/undo and related records. Core reports counts only and does not restore, prune, delete, or export those records’ cell payloads.
  • Core does not call chrome.storage.sync.
  • Optional settings export, share links (fragment-encoded), and diagnostic downloads happen only when you request them; you control onward sharing.

Transmission

  • Developer servers: none in Core command, settings, or worker execution.
  • Third-party AI: none.
  • Google: native commands operate Google’s own editor UI in the open document. Google may save or sync those edits under its own terms; Core does not call the Sheets API.

Permissions

Core requests storage and activeTab, plus content scripts on Google Sheets and Slides document pages. It does not declare identity, OAuth, host API permissions, or native messaging.

SheetSpeed Pro payments

This section applies only if you start a Pro trial or buy Pro. Pro builds also connect to extensionpay.com to check your license.

What we collect for Pro

  • Email address: used to create your ExtensionPay account and link your license to your browser.
  • Plan status: trial start date, plan, and whether you have paid. The extension checks this with ExtensionPay.

What we never collect

Spreadsheet or slide contents, formulas, cell values, or browsing history. Card numbers never reach SheetSpeed or ExtensionPay's servers. Stripe handles them directly.

Processors

  • ExtensionPay (extensionpay.com): license and login service. Privacy policy.
  • Stripe: payment processing, receipts, and the subscription portal. Privacy policy.

Retention and your rights

We keep billing records as long as tax law requires. You can ask us to access or delete your account data by emailing jarvis@agi-jarvis.com. We do not sell personal data.

Children

Core is not directed at children under 13.

Changes

Material changes to data practices should be reflected in an updated published policy and, where required, Chrome Web Store disclosures.
